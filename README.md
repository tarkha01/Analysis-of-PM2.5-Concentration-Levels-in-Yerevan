# Analysis-of-PM2.5-Concentration-Levels-in-Yerevan
This repository contains a Jupyter Notebook implementation of a data science project focused on applying machine learning techniques to real-world data.

The project demonstrates the complete ML workflow: data preprocessing, feature engineering, model training, evaluation, and result analysis.

 Project Description

The goal of this project is to:

Load and preprocess the dataset

Perform exploratory data analysis (EDA)

Apply machine learning algorithms

Evaluate model performance

Interpret and visualize results
